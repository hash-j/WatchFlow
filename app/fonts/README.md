`geist-latin.woff2` is the unmodified Latin variable font shipped with the
installed, locked Next.js 16.2.12 package at
`dist/next-devtools/server/font/geist-latin.woff2` (28,356 bytes).
SHA-256: `1b5ebfb3a01a97343ac96873e6d59a8cb285c66012b6a1ac509cb2765e995ba8`.

Upstream: https://github.com/vercel/geist-font
License: SIL Open Font License 1.1, included at
`public/licenses/geist-OFL.txt` and served at `/licenses/geist-OFL.txt`.

The application loads this checked-in file with `next/font/local`, using
normal variable weights 100–900 and `display: swap`. No font network request
is needed during builds. Build output serves the font from `/_next/static/`.
There is no runtime dependency on the internal Next.js package path.
